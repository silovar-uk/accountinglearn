# CASE 2 倉庫に眠るヒット商品

## 目的

全社売上が増えている状況でも、値引き・高原価の商品構成・過剰発注によって利益率と資金効率が悪化することを学ぶ。全社PLから商品別、さらにSKU別へ分析単位を掘り下げ、会計処理と経営施策をつなげる。

## 会社設定

- 会社名：株式会社ノースゲート・スポーツ
- 業種：スポーツアパレル・応援グッズ
- 従業員：32人
- 状況：過去最高売上を達成した一方、営業利益が減少し、倉庫容量が逼迫

すべて架空の会社・取引・数値である。

## 分析対象SKU

優先対象は、記念セレブレーションTシャツと冬季スタジアムコート。

記念Tシャツは12,000枚を生産し、7,200枚を販売、4,800枚が残る。消化率は60％。取得原価は1枚0.375万円、見込販売価格0.32万円、販売費0.02万円で、正味売却価額は0.30万円となる。

評価差額は1枚0.075万円であり、必要な商品評価損は次のとおり。

```text
4,800枚 × 0.075万円 ＝ 360万円
```

## 推奨提案

### 短期

- 記念Tシャツと冬季コートの追加発注を停止
- 在庫年齢と限界利益を基準に対象SKUだけ段階的に値引く
- セット販売や販売チャネル移管を補助策として検討
- 正味売却価額が取得原価を下回る在庫へ評価損を計上

### 再発防止

- SKU別の消化率・粗利益率・在庫月数を毎週共有
- 追加発注時に予約数、販売速度、残存販売期間を確認
- 最低発注ロットを含む発注判断を複数部門で承認
- 商品別の粗利益下限と在庫年齢ルールを設定
