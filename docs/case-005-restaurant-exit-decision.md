# CASE 5 設計仕様 — 満席の店から撤退すべきか

## 目的

多店舗飲食企業「Table Link」の赤字店舗を題材に、店舗別PLの赤字額と、撤退によって本当に変わる将来キャッシュを分離する。学習者は最初の直感を記録したあと、関連原価、回避可能固定費、埋没原価、撤退コスト、代替投資を段階的に組み立て、条件付きの最終提案まで行う。

## 数値モデル

単位は万円。

| 項目 | 金額 | 意思決定上の扱い |
| --- | ---: | --- |
| 売上高 | 12,000 | 撤退で失う |
| 変動費 | 6,900 | 撤退で回避できる |
| 限界利益 | 5,100 | 売上高 − 変動費 |
| 回避可能固定費 | 3,540 | 撤退で回避できる |
| 回避不能固定費 | 1,020 | 撤退後も残る |
| 本部配賦 | 1,440 | 全社では消えない |
| 店舗営業損失 | △900 | 5,100 − 3,540 − 1,020 − 1,440 |

撤退のみを行う場合の年次利益影響は `回避可能固定費 3,540 − 失う限界利益 5,100 = △1,560`。したがって、店舗PLが赤字でも、代替案がなければ撤退は全社利益を悪化させる。

設備の帳簿価額1,800は過去支出であり、将来意思決定では埋没原価として扱う。一方、売却収入300、撤去費250、違約金600は将来キャッシュであり、即時撤退時の純キャッシュ流出は `250 + 600 − 300 = 550`。教材内では費用総額850と売却収入300を別表示し、混同を防ぐ。

代替投資は初期投資1,800。3年間で単純回収する場合、現店舗を維持するより必要な年間増分利益の最低水準は `1,560 + 1,800 ÷ 3 = 2,160`。

## 学習フロー

1. 初期判断を記録する。正誤では採点せず、後の判断変化と比較する。
2. 店舗別PLを再構成し、売上・変動費・固定費の関係を確認する。
3. 固定費を回避可能・回避不能・配賦へ分類する。
4. 意思決定ブリッジで撤退差額を計算する。答えは計算確認後にのみ表示する。
5. 帳簿価額と将来キャッシュを分離する。
6. 現状維持、90日改善、撤退のみ、代替投資の4案を比較する。
7. 数値条件を含む最終提案を作る。
8. 初期判断と最終判断を並べ、判断の変化を学習記録へ残す。

## UI契約

- CASE 5には `restaurant` テーマを適用し、色は意味補助に限定する。
- 財務資料はデスクトップで展開、モバイルでは先頭資料のみ初期展開する。
- 意思決定ブリッジは、根拠値、増減方向、式、結果の順に読む。
- シナリオカードは同一指標を同じ順序で表示し、モバイルで横スクロールを発生させない。
- 結果画面と学習記録に、初期判断と最終判断を並べる。
- `prefers-reduced-motion` とアプリ内の「動きを少なくする」を尊重する。

```bash
npm run validate:case:005
npm run check
npm run test:e2e
```
